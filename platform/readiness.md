# Describe readiness as the minimum platform path at the start

## Responsibility

Readiness is the platform path an engagement has before substantial business functionality. It states what must be true before the application team depends on the platform for delivery.

## Boundary

Readiness is a practice. It is not a separate product, and it has no public repository of its own. The practice page is the description. This map entry only points at it.

## Where the behavior lives

The practice is [Establish a minimum platform path at the start](../practices/sprint-zero-platform-readiness.md).
