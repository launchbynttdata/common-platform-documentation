# Carry engineering instructions in the module repository

## Responsibility

A Terraform module repository carries the instructions for working in that repository. The instructions name the checks, the file layout, and the kind of module the repository is. They travel with the [skeleton](terraform-skeleton.md), so a module repository receives them with the shared configuration.

## Boundary

The instructions are for the repository that contains them. They are not the team standards. This knowledge base holds the standards. The instructions hold the repository's own checks and layout. A change to a standard is made here. A change to a repository's checks is made in the skeleton or in that repository.

## Where the behavior lives

The current instructions for a module repository start at [AGENTS.md in the skeleton template](https://github.com/launchbynttdata/launch-terraform-skeleton/blob/main/template/AGENTS.md).
