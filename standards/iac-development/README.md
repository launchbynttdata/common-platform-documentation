# Exclusive and shared services

This address is kept because existing links use it. The current standard for where a service lives is [Put an exclusive service with its consumer and a shared service in one repository](../terraform/exclusive-and-shared-services.md).

The page that used to be here is archived at [archive/pre-refresh/standards/iac-development/README.md](../../archive/pre-refresh/standards/iac-development/README.md). The provider-fork procedure on that page is not part of the current standard. The older module class list was replaced by [Hold shared Terraform modules to one contract](../terraform/modules/README.md). The Terragrunt rules on the archived page prescribed a repository layout. Those rules were not carried forward. Current guidance is [Use Terragrunt to orchestrate Terraform across environments and regions](../terraform/terragrunt.md). That standard does not choose a layout.

The module type addresses under `terraform/module/` remain compatibility pages for [Hold shared Terraform modules to one contract](../terraform/modules/README.md).
